# Actress TCG — Fresh Static Edition

This repository has been replaced with a new, simple, dependency-free static website.

Features:
- Username/password login stored in browser localStorage
- Admin demo: 6102000 / 6102000
- Exactly 3 cards per pack
- 1-hour cooldown
- Collection and duplicate counts
- Click any card for full details
- Local leaderboard
- Admin card creation
- No React, Vite, Supabase, npm packages, or build step

Open index.html directly or deploy the repository to any static host.
